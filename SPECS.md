# Project Specifications

## Template status

This template has no selected backend. A derived project must choose either Go
or Node.js with TypeScript and use one backend stack rather than carrying both
by default. No agent may silently choose or migrate the stack. An existing
application keeps its current stack unless migration is a separate approved
task.

Complete this document before implementing the application. Do not select
frameworks, package managers, directory layouts, or tooling until the derived
project records its decisions here.
